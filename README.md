## About Me

I'm **Muskan**, an Electronics and Instrumentation Engineering student at **SGSITS, Indore**, interested in building intelligent systems that solve real-world problems.

My journey started with machine learning and deep learning, and I'm now exploring how to turn these models into useful applications through RAG pipelines, LLM integrations, and Agentic AI.

* Building practical AI/ML projects from experimentation to deployment.
* Exploring Retrieval-Augmented Generation (RAG), LLMs, and AI agents.
* Learning backend development and tools for production-ready AI applications.
* Believer in learning by building, breaking things, and debugging them again.

**Current focus:** AI Engineering · RAG Systems · Agentic AI · Open Source
